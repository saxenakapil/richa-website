# richasaxena.in

Personal website of Richa Saxena. Plain HTML, CSS and JavaScript, no build step.

- `index.html` home page
- `lens.html` photo gallery
- `404.html` "a dog ate this page"
- `images/` photos (see `images/PHOTOS.txt` for names)

Hosted on Vercel. Every push to `main` goes live.
Contact form uses Web3Forms (access key in `index.html`) and delivers to Gmail.
